# VoltRelay hackathon project pack

Start with `index.html` (open in Chrome), then read `project_report.md`. `volt_relay_analysis.ipynb` reproduces the analysis in Google Colab; upload `analyze.py` into the Colab Files panel and set the ZIP_PATH cell to your Drive dataset ZIP.

Contents: responsive dashboard; analysis report; Colab notebook; reproducible Python analyzer; aggregated result CSVs; LinkedIn post draft; one-minute video narration. The source dataset is not included in this package.

The dataset is synthetic. Rates and associations are descriptive. Financial proxy excludes battery depreciation, labour, finance, taxes and overhead. Review these limits before presenting.
